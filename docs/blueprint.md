# **Warmnest - Mental Wellness Application**

## **Application Overview**
Warmnest is a comprehensive mental wellness platform designed to provide users with tools and resources for stress management, emotional well-being, and personal growth. The application combines evidence-based techniques with modern technology to create a supportive environment for mental health.

## **Core Features**

### **1. User Authentication & Profile Management**
- Secure user registration and login system
- Multi-language support (English/Tamil)
- Personalized user profiles with customizable preferences
- Dark/Light mode theme switching
- Profile photo and personal information management

### **2. Onboarding & Assessment**
- Comprehensive onboarding questionnaire
- Stress source identification
- Coping mechanism assessment
- Personal preference collection (favorite colors, gender, etc.)
- Adaptive questionnaire flow based on user responses

### **3. Guided Breathing Exercises**
- Multiple breathing techniques (4-7-8, Box Breathing, Diaphragmatic, etc.)
- Audio-guided sessions with visual animations
- Customizable duration and intensity
- Multi-language audio support
- Progress tracking and session history

### **4. AI-Powered Mental Wellness Chatbot**
- Intelligent conversation capabilities using Google AI
- Multi-language support (English/Tamil)
- Context-aware responses
- Escalation paths for human support
- Conversation history and learning

### **5. Mood Tracking & Journaling**
- Daily mood logging with 5 emotional states
- Rich text journaling capabilities
- Mood trend analysis and visualization
- Offline data entry with online synchronization
- Privacy-focused personal reflection space

### **6. Music Therapy**
- Curated therapeutic music collection
- Multiple genres (calm, energetic, focus, uplifting, gentle, nature)
- Personalized recommendations based on user preferences
- High-quality audio files with album art
- Background play and volume control

### **7. Focus & Productivity Tools**
- Pomodoro timer for focused work sessions
- Two-minute rule implementation for task initiation
- Break reminders and productivity tracking
- Customizable work/break intervals

### **8. Task Assessment & Performance Monitoring**
- Comprehensive task evaluation questionnaires
- Mental challenge assessment
- Physical demand measurement
- Time pressure and stress level tracking
- Performance analytics and insights

### **9. Dashboard & Analytics**
- Centralized overview of all wellness activities
- Progress visualization and trends
- Quick access to all features
- Personalized insights and recommendations

## **Technical Architecture**

### **Frontend Framework**
- Next.js 15.2.3 with React 18.3.1
- TypeScript for type safety
- Tailwind CSS for styling
- Radix UI components for accessibility

### **State Management**
- React Context API for global state
- React Query for server state management
- Local storage for offline capabilities

### **AI Integration**
- Google AI (Genkit) for chatbot functionality
- Natural language processing capabilities
- Context-aware conversation management

### **Data Management**
- CSV-based data storage for simplicity
- Offline-first approach with online synchronization
- Secure data handling and privacy protection

### **Performance Features**
- Service Worker for offline functionality
- Progressive Web App capabilities
- Performance monitoring and optimization
- Bundle analysis and optimization
